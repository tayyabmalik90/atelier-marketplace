# Atelier — premium pre-built website marketplace
Next.js 15 · Tailwind v4 · motion · Postgres (embedded PGlite locally, any Postgres/Supabase in production)

## Run
```
npm install
npm run dev        # http://localhost:3000
```
Seeded admin: admin@atelier.test / admin12345 (change via ADMIN_EMAIL / ADMIN_PASSWORD before first run). Coupons: WELCOME10, LAUNCH20.
Local data lives in `.data/` (delete it to reset).

## Production (Vercel)
Set env vars (see `.env.example`): `DATABASE_URL` (Supabase/Postgres — tables are created automatically), `SESSION_SECRET`, `APP_URL`, `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`, optional `RESEND_API_KEY`.
Stripe webhook endpoint: `/api/webhooks/stripe` (event `checkout.session.completed`).
Without `STRIPE_SECRET_KEY` the built-in test-mode payment page runs (card 4242 4242 4242 4242).

## Known production gaps
- Uploaded images/zips are saved to `storage/` on disk. Vercel's filesystem is read-only/ephemeral, so move uploads to Supabase Storage / S3 before relying on admin uploads in production.
- Auth is built-in (JWT cookie + bcrypt) rather than Supabase Auth; Google sign-in is not implemented.
- Policy pages are starter text, have them reviewed legally. Testimonials in `lib/data.ts` are placeholders, replace with real ones.
- Demo sites are generated by `scripts/gen-demos.mjs` (`npm run gen:demos`); preview images are generated SVG art, not real screenshots.
